# 🍕Pizza Ordering System

## Project Description

The Pizza Ordering System is a frontend web application developed using React.js and JavaScript as part of practical training to improve frontend development skills and logical problem-solving.

The main goal of the project is to simulate a real online pizza ordering experience while focusing on the programming logic behind shopping cart systems, price calculation, item management, and page navigation.

The application displays a fixed list of available pizzas with predefined names, sizes, prices, and images. Users can browse the menu, select pizzas, choose different sizes and quantities, and add them to the shopping cart.

The system automatically updates the total price based on the selected items, quantities, and pizza sizes.

This project focuses on understanding the logic of adding and removing products, managing cart state, handling order confirmation steps, and improving the overall user flow of a modern ordering website.

Projects like shopping carts and ordering systems are considered fundamental learning projects during vocational training in software development, making this project an important practical step in understanding frontend application structure.

---

## 🚀Main Features

* Display available pizza menu with images and prices
* Add pizzas to the shopping cart
* Select pizza size and quantity
* Order multiple pizzas of the same type with different sizes
* Automatic total price calculation
* Increase or decrease item quantity
* Remove items from the cart
* Customer information form
* Address input for delivery
* Order summary and confirmation page
* Final success message after order completion
* Local Storage integration for cart management

---

## 📌 Important Note

This project does not include backend development or database integration.

All displayed pizza data such as names, prices, images, and available sizes are predefined and static.

The shopping cart data is managed using Local Storage to simulate order persistence without requiring a backend server.

The main purpose of the project is frontend logic implementation and UI workflow understanding.
